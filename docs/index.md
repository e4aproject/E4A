# E4A Protocol Documentation

Welcome to E4A — the Ethos for Agents protocol.

**Start with [Project Status](project-status.md).** It is the single source
of truth for what is implemented, what is broken, and what is planned —
verified against the code, not inferred from design documents.

- [Quickstart](quickstart.md) — the verified, runnable developer path, with
  an explicit list of what does not work yet.
- [Protocol](protocol/README.md) — the v1 protocol specification (being
  locked; not yet normative).
- [Security](security.md) — threat model with an implementation-status
  classification for every documented mitigation.
- Reference: [API](reference/api.md) · [CLI](reference/cli.md)

Design and historical documents (`philosophy.md`, `ECOSYSTEM.md`,
`E4A_Level2.1_Validated.md`, `THREAT_MODEL_V2.md`, `attestation_chain_model.md`,
`charter_manifest.md`) describe intent and history. Where they conflict with
the project status document, the status document governs.
